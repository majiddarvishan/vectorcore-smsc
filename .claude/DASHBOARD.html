🔴 Top 10 Priorities

1. REST API Authentication
No auth on management API. Start with loopback, implement BasicAuth or tokens.
2. Diameter Allow-list
No validation of Origin-Host. Require explicit peer configuration and origin verification.
3. SIP Allow-list
REGISTER/NOTIFY without auth. Cache poisoning and message hijacking possible.
4. Safe State Transitions
UpdateMessageStatus is unconditional. Fix BUG-1..4: implement compare-and-set semantics.
5. Persist Error Handling
Failed persist is logged but ignored. Send fails silently without DB records.
6. SQLite Time Comparison
RFC3339 Z vs SQLite datetime (TEXT comparison). Today's retry/expiry messages skip (BUG-5).
7. SMPP Input Validation
submit_sm gets ESME_ROK before decode. Invalid messages accepted silently (BUG-9).
8. Diameter Frame Safety
DWR/DWA/CEA write directly. Concurrent writes interleave bytes and corrupt framing (BUG-12).
9. SMPP Connection Timeout
No read deadline for bind. command_length up to 16MB unauthed. Slowloris + memory DoS (SEC-5).
10. Retention & API Limits
No purge of final messages. limit parameter has no cap. Database growth and query DoS.
